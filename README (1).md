# 💰 Controle Financeiro

Aplicação web para organizar **entradas, saídas e contas em dia**, feita para motoristas de app.

Nasceu de um problema real: quem roda de Uber/99 recebe todo dia, gasta todo dia e, no fim do mês, não sabe pra onde o dinheiro foi.

🔗 **Online:** https://controle-financeiro-36xq.onrender.com/

Funciona no celular, tablet, notebook e desktop, com tema claro e escuro.

## Funcionalidades

- Cadastro e login de usuários
- Lançamento de entradas e saídas, com categorias personalizáveis
- Contas com vencimento e repetição mensal, com checklist de pagas
- Meta do dia: quanto ganhar hoje para ficar com as contas em dia
- Alertas de contas atrasadas ou perto de vencer
- Extrato por período, com gastos por categoria
- Exportação em CSV

## Tecnologias

HTML, CSS e JavaScript · PHP · MySQL · Docker · Render
